# Ask Naren citations show real account/call identifiers, unredacted

Every Ask Naren answer must cite the specific past call it paraphrases — an ungrounded answer is never returned. That call may contain customer- or account-identifying details.

We decided to show citations as-is (real account name, call date) rather than genericizing them.

Ask Naren is internal-only, and CSMs already have access to the underlying transcripts through existing tooling (Avoma). A verifiable, real citation is what makes the answer trustworthy rather than a bare assertion. This should be revisited if Ask Naren's audience ever expands beyond CSMs.
