## Anti-Patterns Verdict

No obvious AI slop. The sunken sidebar, restrained amber accent, and monospace metadata vocabulary are deliberate and correct. The tell: uppercase tracked label is the default fallback for any metadata element — 11+ distinct CSS selectors share the same treatment.

Detector: 2 findings, both layout-transition warnings on progress bar fill elements (globals.css:962, globals.css:3085). Low practical risk.

## Priority Issues

[P1] Placeholder text contrast: --color-ink-placeholder oklch(0.545) against white = ~3.5:1, fails 4.5:1 requirement. Fix: darken to oklch(0.465 0.010 256).

[P1] Modal ARIA on wrong element: role=dialog aria-modal=true on backdrop div, not .lib-modal. No aria-labelledby connecting h2 to dialog. No focus trap. Screen reader experience is broken for both CaseStudyModal and FailureModal.

[P2] Section header animation-fill-mode both hides content during delay: lib-section-header starts at opacity 0 during animation delay. Fix: change both to forwards.

[P2] Uppercase eyebrow overused: 11+ CSS selectors use text-transform uppercase + letter-spacing. Should be one named semantic role (machine-generated badges only).

[P2] .lib-tab missing focus-visible styles: keyboard users see no focus indicator on library tab navigation.
